# Nanten: showcase

Nanten is a modelling and decision platform for the Japanese power market: price, curtailment and
generation forecasts, PPA valuation and FIT-to-FIP conversion, storage, balancing and hedging, on one
engine.

This repository holds the interactive prototypes, published as a website:

| Page | File | What it is |
| --- | --- | --- |
| `/` | `index.html` | The main prototype |
| `/japan` | `japan.html` | The Japan version |
| `/prototype` | `prototype.html` | The full prototype from the Nanten 1.3 package |

The prototypes run entirely in the browser on synthetic data. Figures are illustrative and are not
market data.
